# IPTV Bangladesh — বাংলা নির্দেশনা

## চালান
1. `index.html` ব্রাউজারে খুলুন, অথবা GitHub Pages-এ হোস্ট করুন
2. `playlist_bangladesh.m3u8` লোড করুন — এতে Free-TV/IPTV-এর আপস্ট্রিম প্লেলিস্টের লিংক আছে
3. EPG: https://iptv-org.github.io/epg.xml

## নোট
- শুধুমাত্র free-to-air চ্যানেল
- আপস্ট্রিম প্লেলিস্ট পরিবর্তন হলে এই ফাইল আপডেট করতে হবে
